## Contexto do Projeto

Este projeto é um trabalho escolar da disciplina **Programação Orientada a Objetos – Módulo 3**, ministrada pela professora **Luciene Motta**.

O sistema deve ser desenvolvido em **PHP Orientado a Objetos**, com formulário HTML para entrada de dados, processamento em PHP e exibição formatada dos resultados.

O tema escolhido é:

**Problema 3: Sistema de Cooperativas de Reciclagem**

O objetivo do sistema é representar diferentes materiais recicláveis e calcular seu valor de venda, ajudando uma cooperativa a controlar materiais recebidos, calcular valores e organizar a produção.

O projeto deve ser simples, funcional e bem apresentado, demonstrando corretamente os conceitos de orientação a objetos.

---

## Objetivo Principal

Criar um pequeno sistema em PHP OO que permita ao usuário informar dados de materiais recicláveis, como:

- Descrição do material
- Peso em kg
- Valor por quilo
- Tipo específico do material
- Dados extras dependendo do tipo de material
