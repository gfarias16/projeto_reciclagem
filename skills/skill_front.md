## Skill Especial: Manutenção e Correção Contínua do Front-End

Sempre que houver qualquer alteração no projeto, o agente deve verificar se a interface visual continua funcionando corretamente.

O front-end deste projeto deve ser tratado como uma parte importante da entrega, não apenas como algo secundário. Como o sistema será apresentado para a professora, ele precisa parecer organizado, moderno, limpo e sem erros visuais.

---

## Objetivo desta Skill

Garantir que, a cada nova atualização no código PHP, HTML ou CSS, o layout continue:

- Bonito
- Responsivo
- Alinhado
- Organizado
- Sem elementos quebrados
- Sem campos desalinhados
- Sem botões fora do padrão
- Sem diferenças visuais entre telas
- Sem perda de legibilidade
- Sem erros em telas menores

---

## Regra Principal

Sempre que o agente modificar qualquer arquivo do projeto, ele deve revisar também os possíveis impactos no front-end.

Mesmo que a alteração seja no PHP, o agente deve pensar:

```txt
Essa mudança pode afetar a tela?
Essa mudança pode quebrar algum card?
Essa mensagem de erro está bonita?
O resultado continua bem formatado?
O botão de voltar continua aparecendo corretamente?
O layout continua responsivo?
